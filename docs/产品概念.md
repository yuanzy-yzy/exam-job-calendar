# 产品概念

## 一句话定位

公考与求职截止日历，是一个把“我下一步该做什么”持续放在桌面上的本地时间控制台。

## 要解决的问题

公务员考试与求职流程都不是单一日期，而是一串不能遗漏的节点：报名、缴费、打印准考证、笔试、资格复审、面试、体检、政审，以及网申、宣讲会、笔试确认和面试。信息通常分散在公告、招聘网站、聊天记录和浏览器收藏中，用户需要反复查找，容易错过截止时间，也很难建立整体节奏感。

本产品不试图成为复杂的项目管理系统，而是聚焦三件事：

1. 一眼看清今天与未来几天最重要的动作。
2. 用倒计时和提醒降低错过关键节点的风险。
3. 让数据只留在本机，使用者不必以隐私换便利。

## 设计原则

### 1. 截止日优先

普通日历以“发生时间”为中心，本产品同时突出“开始时间”和“截止时间”。今天截止的事项置顶，逾期未完成的事项保持可见。

### 2. 信息密度与可读性并重

桌面端允许展示更多上下文，但信息必须有层级。颜色表达事项类型，红色表达逾期，勾选表达完成；文字大小既能随窗口变化，也能由用户手动控制。

### 3. 本地优先

新增、编辑、提醒、统计、备份均可离线完成。应用不要求注册账号，不默认上传数据，也不依赖付费 API。

### 4. 渐进式复杂度

用户可以只创建一个标题和截止时间，也可以继续补充地点、链接、备注、优先级、状态和多组提醒。简单任务保持简单，重要节点仍能被完整记录。

### 5. 桌面常驻但不过度打扰

小组件负责“扫一眼”，完整窗口负责“管理”；系统通知只在用户为事项启用提醒时出现，逾期持续提醒也可关闭。

## 核心使用路径

1. 创建“国考报名截止”“省考笔试”或“某公司网申截止”等事项。
2. 在桌面小组件查看最近截止事项与重要倒计时。
3. 在月、周或议程视图中调整计划，并将完成事项打勾。
4. 定期导出或备份本地数据，必要时一键恢复。

## 后续演进方向

- 完善跨平台打包与 macOS 系统集成
- 提供更细粒度的重复事项和提醒规则
- 增加数据导入映射与冲突预览
- 在不上传个人日程的前提下，改进公开招聘信息订阅流程
- 增加无障碍能力、键盘操作和更丰富的字体缩放策略
