# 隐私与本地数据

## 数据边界

应用采用本地优先设计。用户创建的标题、时间、地点、链接、备注、提醒、完成状态及界面设置，默认保存在当前 Windows 用户目录下：

```text
E:\公考求职日历数据
```

主数据库为 `calendar.db`，本机设置为 `settings.json`，备份位于 `backups` 子目录。若电脑没有 E 盘，程序会回退到 `%APPDATA%\ExamJobCalendar`。应用核心功能不需要登录，也不会主动把这些数据上传到网络。

## 本仓库不包含的内容

版本库通过 `.gitignore` 排除以下内容：

- SQLite 数据库及其 WAL / SHM 文件
- 自动与手动备份
- 本机设置和错误日志
- Python 虚拟环境、缓存和构建中间文件
- 已生成的 EXE 和其他打包产物
- 自动采集任务每次运行生成的数据快照

## 公开发布前检查

维护者在推送公开仓库前应执行：

```powershell
git status --short
git ls-files
```

确认文件列表中没有 `calendar.db`、`settings.json`、导出的日程文件或含个人路径的日志。若文件曾经被提交，仅添加 `.gitignore` 不会清除历史记录，需要从 Git 历史中移除后再公开。

## 备份建议

公开源码仓库不是日程备份。日程数据应使用应用内的“数据与备份”功能另行保存到可信位置；分享备份前，请注意其中可能包含求职单位、考试计划、链接和个人备注等敏感信息。
